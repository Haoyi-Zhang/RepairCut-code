# Third-party materials

No third-party implementation, solver, benchmark, dataset, paper PDF, or font file
is distributed in this standalone repository. All scientific cases are generated
by the included original constructors. Python is a runtime prerequisite, not bundled.

The containing project additionally retains the supplied `paper/IEEEtran.cls` and
`paper/IEEEtran.bst` unchanged. Their original contributor and copyright notices
are intact. Both state the LaTeX Project Public License 1.3. They are not covered
by this repository's MIT license. The LPPL is supplied by a normal TeX distribution.
A structural match to this supplied family does not establish current TPDS approval.

Public scholarly materials are cited, not copied. Public availability was not
assumed to grant redistribution permission. See `external_resources.csv` for the
exact source URLs, access date, integration mode and unresolved licensing details.
